## [v0.1.0] - 2026-09-12 ([`ea243a8`](https://github.com/plexusone/uiforge/commit/ea243a8))

### Highlights

- Specification-driven UI composition platform: pages are declarative PageSpec JSON (apiVersion ui.plexusone.dev/v1) validated against a versioned component registry, with Go types as the source of truth and generated JSON Schemas
- Two fully parallel renderers — React and standard web components via Lit — emitting an identical data-uiforge-* DOM vocabulary, verified by fixture-driven cross-renderer conformance suites
- Async data-source runtime in both renderers: pluggable connectors, loading/error states, per-component caching, and cache invalidation via the component.refresh interaction action
- Design-system integration built on design-system-spec (DSS): components consume a fixed semantic token vocabulary, and the theme adapter maps any DSS document onto it — including white-label var() references to the host brand's own CSS custom property prefix

- Component registry with ComponentSpec manifests and page validation, builtin core/analytics/assistant/application namespaces (25 manifests), external manifest loading (file and directory), version compatibility checking (exact, prefix, and caret forms), and instance property validation against manifest schemas ([`a47ec45`](https://github.com/plexusone/uiforge/commit/a47ec45))
